H

Heart for Health

Parhelion Software, for Heart for health ICT B.V. · 2021 – 2022 · View on the App Store

Patients track blood pressure, heart rate and other readings from a Bluetooth device, and get daily tasks such as questionnaires and measurements.

I joined an existing project and took it through to App Store distribution: integrated an Objective-C Bluetooth library, added local storage for user data, built custom charts for readings over time, and worked with FHIR (Fast Healthcare Interoperability Resources) for medical data. I also wrote unit, integration and UI tests on Bitrise, with the UI tests capturing screenshots for each release.

Built with Swift, Objective-C, RxSwift, Couchbase Lite, Bluetooth, OpenID, FHIR, Twilio, Bitrise
